# P5 前端接口对接指南：歌词

面向：不了解后端的前端工程师。本文说明歌词功能该如何调用接口、展示歌词、以及如何处理各种边界情况。

> 基础信息：
> - 后端基地址：`http://localhost:4000`
> - 所有接口返回格式为：
> ```ts
> interface ApiResponse<T = unknown> {
>   success: boolean;
>   code: number;
>   message: string;
>   data?: T;
> }
> ```
> - 管理端接口需要登录且角色为 `owner` / `admin` / `song_admin`，需携带 Access Token。

---

## 一、功能概览

歌词系统支持两种来源：
- **AI 自动生成**：后端在首次请求时自动从 B 站拉取 AI 字幕并转换为 LRC 格式。如果 B 站字幕尚未生成（异步任务），6 小时后会自动重试。
- **人工上传**：管理员手动上传标准 LRC 文件，质量更高，优先展示。

前端只需调用一个公共接口，后端已处理好优先级（人工版 > AI 版 > 自动生成）。

---

### 公共接口

## 三、公共接口：获取歌词

### GET `/api/songs/:id/lyrics`

**路径参数**
| 参数 | 类型 | 说明 |
|------|------|------|
| `id` | number | 歌曲 ID |

**无需请求体，无需登录。**

---

### 响应：有歌词时（`available: true`）

```ts
interface LyricAvailableResponse {
  available: true;
  songId: number;
  lyricId: number;
  versionId: number;
  /** 来源类型，见下方枚举 */
  sourceType: 'MANUAL' | 'BILIBILI_AI_SUBTITLE';
  /** 版本质量 */
  qualityStatus: 'VERIFIED' | 'AI_GENERATED' | 'NEEDS_REVIEW';
  /** 格式，目前固定为 LRC */
  format: 'LRC';
  /** 同步模式，目前固定为 LINE（逐行） */
  syncMode: 'LINE';
  /** 免责声明（AI 生成时有值，人工上传为 null） */
  disclaimer: string | null;
  /** 逐行歌词数组，已按 startMs 升序排列 */
  lines: LyricLine[];
}

interface LyricLine {
  /** 歌词开始时间，毫秒 */
  startMs: number;
  /** 歌词结束时间，毫秒（可能为 undefined，需自行用下一行 startMs 推算） */
  endMs?: number;
  /** 歌词文本，已去除 ♪ 符号 */
  text: string;
}
```

**示例响应**
```json
{
  "success": true,
  "code": 200,
  "message": "获取歌词成功",
  "data": {
    "available": true,
    "songId": 431,
    "lyricId": 12,
    "versionId": 34,
    "sourceType": "BILIBILI_AI_SUBTITLE",
    "qualityStatus": "AI_GENERATED",
    "format": "LRC",
    "syncMode": "LINE",
    "disclaimer": "该歌词由 AI 字幕自动生成，可能存在识别错误",
    "lines": [
      { "startMs": 4320, "endMs": 8640, "text": "夜已深了灯还亮着" },
      { "startMs": 8640, "endMs": 13100, "text": "窗外的风吹过了树梢" }
    ]
  }
}
```

---

### 响应：暂无歌词时（`available: false`）

HTTP 状态码仍为 **200**，不抛错误，前端需检查 `data.available`。

```ts
interface LyricUnavailableResponse {
  available: false;
  songId: number;
  /** 暂无歌词的原因（仅供调试，不建议直接展示给用户） */
  reason: string;
}
```

**示例响应**
```json
{
  "success": true,
  "code": 200,
  "message": "暂无歌词",
  "data": {
    "available": false,
    "songId": 431,
    "reason": "暂无字幕，B 站字幕可能尚未生成"
  }
}
```

> `reason` 常见取值含义：
> - 包含"冷却"：上次尝试失败后进入 6 小时冷却期，前端无需特殊处理，等待即可。
> - 包含"需要登录"：B 站接口要求登录（Cookie 失效），需联系管理员刷新 Cookie。
> - 其他：B 站字幕尚未生成（新上传视频的常见情况）。

## 四、前端歌词展示集成指南

### 1. 基本渲染流程

```ts
// 1. 请求歌词
const res = await fetch(`/api/songs/${songId}/lyrics`);
const json = await res.json();

if (!json.data.available) {
  // 展示占位符："歌词努力同步中..."
  return;
}

const { lines, disclaimer } = json.data;
```

### 2. 如何高亮当前行（逐行卡拉OK效果）

`lines` 数组已按 `startMs` 升序排列，结合播放器当前时间即可确定高亮行：

```ts
/**
 * 根据当前播放时间（毫秒）获取当前歌词行索引。
 * 如果当前时间早于第一行，返回 -1。
 */
function getCurrentLineIndex(lines: LyricLine[], currentMs: number): number {
  let idx = -1;
  for (let i = 0; i < lines.length; i++) {
    if (lines[i].startMs <= currentMs) {
      idx = i;
    } else {
      break;
    }
  }
  return idx;
}

// 在播放器 timeupdate 事件中调用：
player.on('timeupdate', () => {
  const currentMs = player.currentTime * 1000;
  const idx = getCurrentLineIndex(lines, currentMs);
  setActiveLine(idx);
});
```

### 3. 处理 `endMs` 缺失

当某行的 `endMs` 为 `undefined` 时，可使用下一行的 `startMs` 作为结束时间（最后一行可使用音频总时长）：

```ts
function getEndMs(lines: LyricLine[], index: number, audioDuration: number): number {
  return lines[index].endMs
    ?? lines[index + 1]?.startMs
    ?? audioDuration * 1000;
}
```

### 4. 免责声明展示建议

当 `disclaimer` 不为 `null` 时，建议在歌词区顶部或底部以小字灰色展示：

```tsx
{disclaimer && (
  <p className="text-xs text-gray-400 text-center mt-2">{disclaimer}</p>
)}
```

### 5. 完整 TypeScript 类型定义

```ts
// 可复制到 src/types/lyrics.ts

export interface LyricLine {
  startMs: number;
  endMs?: number;
  text: string;
}

export interface LyricAvailable {
  available: true;
  songId: number;
  lyricId: number;
  versionId: number;
  sourceType: 'MANUAL' | 'BILIBILI_AI_SUBTITLE';
  qualityStatus: 'VERIFIED' | 'AI_GENERATED' | 'NEEDS_REVIEW';
  format: 'LRC';
  syncMode: 'LINE';
  disclaimer: string | null;
  lines: LyricLine[];
}

export interface LyricUnavailable {
  available: false;
  songId: number;
  reason: string;
}

export type GetLyricsResult = LyricAvailable | LyricUnavailable;
```

## 五、管理端接口详情

> 以下接口均需登录，且角色为 `owner`、`admin` 或 `song_admin`。

---

### GET `/api/admin/songs/:id/lyrics`

查看指定歌曲的所有歌词资源及完整版本历史，用于管理界面展示。

**响应 data**：歌词资源数组，每个资源含 `versions` 版本列表。

```ts
interface AdminLyricResource {
  id: number;
  songId: number;
  type: 'ORIGINAL' | 'TRANSLATION' | 'TRANSLITERATION';
  language: string;           // 如 "zh-CN"
  status: 'DRAFT' | 'PUBLISHED' | 'ARCHIVED';
  generationStatus: 'NONE' | 'SUCCESS' | 'FAILED' | 'NO_SUBTITLE';
  generationError: string | null;
  lastGenerateAttemptAt: string | null;
  currentVersionId: number | null;
  versions: AdminLyricVersion[];
}

interface AdminLyricVersion {
  id: number;
  versionNo: number;
  sourceType: 'MANUAL' | 'BILIBILI_AI_SUBTITLE';
  qualityStatus: 'VERIFIED' | 'AI_GENERATED' | 'NEEDS_REVIEW';
  format: 'LRC';
  syncMode: 'LINE';
  rawContent: string;         // 完整 LRC 文本
  lineCount: number;
  disclaimer: string | null;
  createdAt: string;
  createdByUserId: number | null;
}
```

---

### POST `/api/admin/songs/:id/lyrics`

上传人工 LRC，自动设为当前发布版本。若该歌曲已有歌词资源，会在现有资源上追加新版本并覆盖当前版本。

**请求体**
```ts
{
  /** 标准 LRC 格式文本，1 ~ 200000 字符 */
  rawContent: string;
}
```

**示例请求体**
```json
{
  "rawContent": "[00:12.00]第一行歌词\n[00:15.50]第二行歌词\n[00:19.30]第三行歌词"
}
```

**响应 data**
```ts
{
  lyricId: number;
  version: AdminLyricVersion;
}
```

---

### POST `/api/admin/songs/:id/lyrics/:lyricId/versions`

在已有歌词资源上追加新版本，适合修订歌词时保留历史。

**路径参数**
| 参数 | 说明 |
|------|------|
| `id` | 歌曲 ID |
| `lyricId` | 歌词资源 ID（通过上方 GET 接口获取） |

**请求体**
```ts
{
  rawContent: string;
  /** 是否立即发布为当前版本，默认 true */
  publish?: boolean;
  /** 版本质量，默认 VERIFIED */
  qualityStatus?: 'VERIFIED' | 'NEEDS_REVIEW';
}
```

**响应 data**：`AdminLyricVersion` 对象

---

### POST `/api/admin/songs/:id/lyrics/:lyricId/versions/:versionId/publish`

将指定历史版本发布为当前版本（用于版本回滚）。

**路径参数**
| 参数 | 说明 |
|------|------|
| `id` | 歌曲 ID |
| `lyricId` | 歌词资源 ID |
| `versionId` | 要发布的版本 ID |

**响应 data**
```ts
{
  lyricId: number;
  versionId: number;
}
```

---

### POST `/api/admin/songs/:id/lyrics/generate`

强制重新从 B 站拉取 AI 字幕（忽略 6 小时冷却期）。适合在 B 站字幕已生成、但系统尚未获取时手动触发。

**无请求体。**

**响应 data**：同公共接口 `GetLyricsResult`（`available: true/false`）

---

## 六、LRC 格式说明

上传歌词时需使用标准 LRC 格式：

```
[mm:ss.xx]歌词文本
```

**示例**
```
[00:12.00]夜已深了灯还亮着
[00:15.50]窗外的风吹过了树梢
[00:19.30]我在想你是否也在
[00:23.10]看着同一颗星星
```

**注意事项**
- 时间戳格式：`[分:秒.百分秒]`，如 `[02:35.48]`
- 每行一条歌词，换行符为 `\n`
- 不支持 ID 标签（`[ti:]`、`[ar:]` 等），可忽略
- 不建议同一时间点有多行歌词（后端只保留最后一行）

## 七、常见问题

**Q：首次请求某首歌的歌词，响应较慢是正常的吗？**

正常。后端在无缓存时会同步请求 B 站接口拉取字幕，首次可能需要 1-3 秒。之后 1 小时内会命中 Redis 缓存，响应极快。

**Q：`available: false` 且 reason 包含"冷却"，前端要怎么处理？**

展示"歌词努力同步中..."即可，不需要前端主动轮询。系统会在 6 小时冷却结束后在下一次用户请求时自动重试。

**Q：`disclaimer` 什么时候会有值？**

当歌词由 B 站 AI 字幕生成时（`sourceType === 'BILIBILI_AI_SUBTITLE'`），`disclaimer` 为 `"该歌词由 AI 字幕自动生成，可能存在识别错误"`；人工上传时为 `null`。

**Q：`lines` 中第一行 `text` 和 `disclaimer` 一样，重复了？**

不会再重复。AI 免责声明由独立的 `disclaimer` 字段承载，`lines` 只返回真实歌词行。历史数据中如果曾在 `[00:00.00]` 注入过免责声明，服务端会在公共接口响应时过滤掉。
