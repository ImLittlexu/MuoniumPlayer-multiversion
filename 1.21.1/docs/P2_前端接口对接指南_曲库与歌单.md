# P2 前端接口对接指南：曲库与我的歌单

面向：不了解后端的前端工程师。本文说明“曲库”与“我的歌单”页面该如何调用接口与展示数据。

> 基础信息：
> - 后端基地址：`https://api.ggd.fan`
> - 所有接口返回格式为：
> ```ts
> interface ApiResponse<T = unknown> {
>   success: boolean;
>   code: number;
>   message: string;
>   data?: T;
> }
> ```
> - 需要登录的接口必须携带 Access Token（已在现有认证流程中配置）。

---

## 一、页面概览

### 1. 曲库（Songs Library）
- 功能：浏览歌曲列表、搜索、筛选、进入详情（如需要）、收藏、查看评论。
- 重要展示规则：**列表只展示歌曲封面、歌名、原唱**。
  - **不展示**播放量、收藏量、热度（这些数据用于首页推荐）。

### 2. 我的歌单（My Library）
包含三个子页签：
- **收藏**：用户收藏的歌曲列表
- **最近播放**：用户最近播放历史
- **歌单**：用户自建歌单列表、创建歌单、查看详情、管理歌曲顺序

---

## 二、接口一览

### 曲库相关接口（/api/songs）
| 方法 | 路径 | 说明 | 是否需要登录 |
|------|------|------|--------------|
| GET | `/api/songs` | 歌曲列表（分页、搜索、筛选、排序） | 否 |
| GET | `/api/songs/filters` | 获取筛选项（语种、风格） | 否 |
| GET | `/api/songs/:id` | 歌曲详情 | 否 |
| GET | `/api/songs/:id/comments` | 评论列表 | 否 |
| POST | `/api/songs/:id/comments` | 添加评论 | 是 |
| POST | `/api/songs/:id/like` | 收藏歌曲 | 是 |
| DELETE | `/api/songs/:id/like` | 取消收藏 | 是 |
| POST | `/api/songs/:id/play` | 记录播放 | 否（匿名可用） |

### 我的歌单相关接口（/api/playlists）
| 方法 | 路径 | 说明 | 是否需要登录 |
|------|------|------|--------------|
| GET | `/api/playlists` | 我的歌单列表 | 是 |
| GET | `/api/playlists/public` | 公开歌单列表（可选） | 否 |
| GET | `/api/playlists/discover` | 歌单发现页（搜索/排序/筛选） | 否（登录可返回收藏状态） |
| GET | `/api/playlists/favorites` | 我收藏的歌单列表 | 是 |
| GET | `/api/playlists/:id` | 歌单详情 | 否（私有需登录且是所有者） |
| POST | `/api/playlists` | 创建歌单 | 是 |
| PUT | `/api/playlists/:id` | 更新歌单 | 是 |
| DELETE | `/api/playlists/:id` | 删除歌单 | 是 |
| POST | `/api/playlists/:id/favorite` | 收藏歌单 | 是 |
| DELETE | `/api/playlists/:id/favorite` | 取消收藏 | 是 |
| POST | `/api/playlists/:id/songs` | 添加歌曲到歌单 | 是 |
| DELETE | `/api/playlists/:id/songs/:songId` | 从歌单移除歌曲 | 是 |
| PUT | `/api/playlists/:id/songs/order` | 调整歌曲顺序 | 是 |

### 收藏与播放历史（/api/songs）
| 方法 | 路径 | 说明 | 是否需要登录 |
|------|------|------|--------------|
| GET | `/api/songs/likes` | 我的收藏列表 | 是 |
| GET | `/api/songs/history` | 最近播放列表 | 是 |

## 三、曲库页面对接指南

### 1) 获取筛选项
**请求**
```
GET /api/songs/filters
```
**响应 data**
```ts
{
  languages: string[];
  styles: string[];
}
```

### 2) 歌曲列表（分页/搜索/筛选/排序）
**请求**
```
GET /api/songs?keyword=...&language=...&style=...&page=1&pageSize=20&sortBy=createdAt&sortOrder=desc
```
**参数说明**
- `keyword`：模糊搜索（歌名/原唱）
- `language`：语种（可选）
- `style`：风格（可选）
- `page`：页码（从1开始）
- `pageSize`：每页条数（1-100）
- `sortBy`：`createdAt | playCount | favCount | heatScore`
- `sortOrder`：`asc | desc`

**响应 data**
```ts
{
  items: Array<{
    id: number;
    songName: string;
    originalArtist: string[];
    languages: string[];
    styles: string[];
    bv: string;
    cid: bigint;
    coverUrl: string | null;
    remarks: string | null;
    createdAt: string;
    isLiked?: boolean;
    // stats 字段存在但曲库页面不展示
    stats?: { playCount: number; favCount: number; heatScore: number };
  }>;
  pagination: {
    page: number;
    pageSize: number;
    total: number;
    totalPages: number;
  };
}
```

**前端展示要求**
- 只显示：**封面（coverUrl）/歌名（songName）/原唱（originalArtist）/风格(styles)**
- **不显示**：`playCount` / `favCount` / `heatScore`

### 3) 收藏/取消收藏
**收藏**
```
POST /api/songs/:id/like
```
**取消收藏**
```
DELETE /api/songs/:id/like
```

### 4) 记录播放（播放超过 30s 才算一次）
后端接口：
```
POST /api/songs/:id/play
```

**前端规则（必须实现）**
- 只有**单次播放超过 30 秒**才允许调用该接口。
- 建议实现方式：
  - 播放器 `timeupdate` 或计时器，当播放时长累计 ≥ 30s 且未上报过该歌曲，就调用 `/play`。
  - 若用户暂停/切歌，计时归零，重新累计。
  - 对同一首歌曲，**一次播放只上报一次**。

## 四、“我的歌单”页面对接指南

### A. 收藏页签
**请求**
```
GET /api/songs/likes?page=1&pageSize=20
```
**响应结构与曲库一致**，只展示封面/歌名/原唱。

### B. 最近播放页签
**请求**
```
GET /api/songs/history?page=1&pageSize=20
```
**响应 data**
```ts
{
  items: Array<{
    id: number;
    songName: string;
    originalArtist: string[];
    coverUrl: string | null;
    userPlayCount: number;
    lastPlayedAt: string;
  }>;
  pagination: {...}
}
```

### C. 歌单页签

#### 1) 我的歌单列表
```
GET /api/playlists?page=1&pageSize=20
```
**响应 data**
```ts
{
  items: Array<{
    id: number;
    title: string;
    coverUrl: string | null;
    isPublic: boolean;
    songCount: number;
    createdAt: string;
    updatedAt: string;
    user: { id: number; uid: bigint; username: string; avatarUrl: string | null };
  }>;
  pagination: {...}
}
```

#### 2) 创建歌单
```
POST /api/playlists
```
**请求体**
```ts
{
  title: string;          // 必填
  coverUrl?: string|null; // 可选
  isPublic?: boolean;     // 可选，默认 true
}
```

**关于“默认封面”规则（必须遵守）**
- 需求：创建的歌单**默认封面为第一首歌的 cover_url**。
- 后端在创建歌单时不会自动设置封面（因为此时可能还未添加歌曲）。
- **前端实现方式：**
  1) 创建歌单时 `coverUrl` 可以先传 `null`。
  2) 当用户首次添加歌曲到歌单时，若歌单封面为空，则前端应调用更新歌单接口，将封面设置为该歌曲的 `coverUrl`。

#### 3) 添加歌曲到歌单
```
POST /api/playlists/:id/songs
```
**请求体**
```ts
{ songId: number }
```

#### 4) 更新歌单（用于设置封面/修改标题/公开状态）
```
PUT /api/playlists/:id
```
**请求体**
```ts
{
  title?: string;
  coverUrl?: string | null;
  isPublic?: boolean;
}
```

#### 5) 歌单详情
```
GET /api/playlists/:id
```
**响应 data**
```ts
{
  id: number;
  title: string;
  coverUrl: string | null;
  isPublic: boolean;
  songCount: number;
  createdAt: string;
  updatedAt: string;
  user: {...};
  stats?: { favoriteCount: number; viewCount: number; shareCount: number };
  songs: Array<{
    songId: number;
    sortOrder: number;
    addedAt: string;
    song: { id: number; songName: string; originalArtist: string[]; bv: string; cid: bigint; coverUrl: string | null }
  }>;
  isFavorited?: boolean; // 登录后返回
  isOwner?: boolean;     // 登录后返回
}
```

#### 6) 调整歌曲顺序
```
PUT /api/playlists/:id/songs/order
```
**请求体**
```ts
{ songIds: number[] }  // 按新顺序排列，必须包含全部歌曲
```

#### 7) 删除歌单
```
DELETE /api/playlists/:id
```

### D. 歌单发现页（歌单广场）

#### 1) 获取发现列表
```
GET /api/playlists/discover?page=1&pageSize=20&keyword=xxx&sortBy=hot&creatorId=10
```
**参数说明**
- `page`：页码（从1开始）
- `pageSize`：每页条数（1-100）
- `keyword`：模糊搜索（歌单标题/创建者用户名）
- `sortBy`：`hot | new | favorite | songCount`
- `creatorId`：创建者用户ID（可选）

**响应 data**
```ts
{
  items: Array<{
    id: number;
    title: string;
    coverUrl: string | null;
    isPublic: boolean;
    songCount: number;
    createdAt: string;
    updatedAt: string;
    user: { id: number; uid: string; username: string; avatarUrl: string | null };
    stats?: { favoriteCount: number; viewCount: number; shareCount: number };
    isFavorited?: boolean; // 登录后返回
  }>;
  pagination: {...}
}
```

### E. 歌单收藏功能

#### 1) 收藏歌单
```
POST /api/playlists/:id/favorite
```
**响应 data**
```ts
{ playlistId: number; favorited: true }
```

#### 2) 取消收藏歌单
```
DELETE /api/playlists/:id/favorite
```

#### 3) 获取我的收藏歌单列表
```
GET /api/playlists/favorites?page=1&pageSize=20&sortBy=favoriteTime
```
**参数说明**

**响应 data**

## 五、前端实现注意事项

1) **播放记录必须满足“>30秒”规则**再调用 `/api/songs/:id/play`。
2) 曲库与收藏/播放历史列表**只显示封面、歌名、原唱**。
3) 歌单默认封面规则：
   - 创建歌单后，首次添加歌曲时，如封面为空，前端需调用更新接口设置封面。
4) 需要登录的接口若返回 `code=4002`，应引导用户重新登录。

1. 页面加载：

2. 搜索：
   - `GET /api/songs?keyword=xxx&page=1&pageSize=20`
3. 收藏：
   - `POST /api/songs/:id/like`
4. 播放 >30s：
   - `POST /api/songs/:id/play`
